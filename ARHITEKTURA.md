# Как устроено и почему так

Это переписанный с нуля десктопный клиент. До него в репозитории лежал форк
GUI.for.SingBox: 13 800 строк чужого фронтенда и Go-моста, из которых под Kelevra
было поправлено восемь коммитов. Всё остальное — редактор правил, менеджер
профилей, система плагинов — к продукту отношения не имеет, но ломается и
обновляется вместе с апстримом.

## Три решения, на которых стоит всё остальное

**1. Ни одной строки на C.** Всё приложение — чистый Go, `CGO_ENABLED=0`.
Из этого следует главное: `Kelevra.exe` собирается на любой машине, в том числе
на Linux-сервере, за секунды и одной командой. Форк на Wails так не умел — его
сборка требовала Windows. Цена: окно рисует не своя библиотека виджетов, а
системный WebView2, который есть в Windows 10 и 11 из коробки.

**2. Интерфейс — страница, работа — локальный HTTP API.** Окно ходит на
`127.0.0.1` со случайным ключом в пути; тот же API отвечает и в браузере.
Из этого следует, что всю работу приложения — код доступа, скачивание конфига,
запуск ядра, счётчики — можно проверить без Windows и без окна вообще.
Проверка приложения перестаёт зависеть от того, у кого под рукой Windows.

**3. Ядро — отдельный процесс, а не библиотека.** Приложение порождает
`sing-box.exe`, следит за ним и гасит его при выходе; состояние спрашивает у
Clash API ядра (`127.0.0.1:20123`) — так же, как это делает мобильный клиент.
Из этого следует, что ядро можно обновлять отдельно от приложения, а падение
ядра видно пользователю строкой из его же лога, а не словом «ошибка».

## Части

| Папка | Что делает |
|---|---|
| `cmd/kelevra` | запуск: поднять службу, открыть окно; вне Windows — напечатать адрес |
| `internal/sluzhba` | HTTP API приложения и встроенная страница интерфейса |
| `internal/podpiska` | разговор с сервером подписки по коду доступа |
| `internal/yadro` | запуск, остановка, показания и самостоятельная загрузка ядра |
| `internal/hranenie` | где лежат данные пользователя и настройки |

## Протокол сервера подписки

Тот же, что у мобильного клиента `kelevra-box`:

- `GET https://subkv.chickenkiller.com/k/<код>` → готовый `config.json` для ядра;
- `GET https://subkv.chickenkiller.com/k/<код>/info?device=<id>` → имя, срок, трафик.

Десктопный форк ходил на `/s/<код>`. Какой из путей сейчас живой, снаружи без
настоящего кода доступа не различить: сервер на выдуманный код отвечает 404 на
обоих. Поэтому клиент пробует оба по очереди — сначала мобильный `/k/`.

## Что решено отложить

- **Трей и автозапуск.** Окно и трей на Windows делят один поток сообщений;
  сделать это правильно — отдельная работа, а без неё приложение уже полезно.
- **Выбор узла и режимы.** Пока применяется ровно тот конфиг, что прислал сервер.
- **TUN.** Ядру нужны права администратора. Без них приложение выбрасывает из
  профиля вход-туннель и работает прокси-режимом, а кнопка «Включить полную
  защиту» перезапускает приложение с правами (`internal/prava`).


## Профиль сервера — телефонный, чинится на месте (`internal/konfig`)

Сервер подписки отдаёт один профиль всем клиентам, и написан он под Android.
Проверено настоящим ядром (`sing-box check`) на настоящем профиле:

- `route.override_android_vpn` — ядро вне Android падает сразу: `is only
  supported on Android`. То есть без правки конфига приложение на компьютере
  не работает вообще, и никакая кнопка этого не лечит;
- у входа `tun-in` есть `exclude_package` и `platform.http_proxy` — поля
  телефона, на компьютере они не значат ничего;
- Clash API профиль поднимает на своём адресе (`experimental.clash_api`,
  у нас `127.0.0.1:9090`). Зашитый в приложении адрес его не угадает —
  приложение решит, что живое ядро мертво, и убьёт процесс. Адрес берём из профиля;
- второй вход `mixed-in` (`127.0.0.1:2412`) — это и есть прокси-режим.
  Чтобы система о нём знала, просим ядро прописать себя системным прокси.

Отступление вместо падения: если система настроить прокси не даёт, ядро именно
**падает** (`initialize system proxy: unsupported desktop environment`, поймано
живьём на стенде). Приложение перезапускает ядро без этой просьбы и показывает
адрес прокси в окне — половина защиты лучше, чем ничего.
