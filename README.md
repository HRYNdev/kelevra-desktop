# Kelevra для компьютера

Приложение Kelevra под Windows: ввёл код доступа — нажал «Подключить».

Один файл `Kelevra.exe`, ставить ничего не нужно. Ядро sing-box приложение
скачивает себе само при первом подключении (из релизов этого репозитория,
теги `core-*`). Всё своё оно держит в `%LOCALAPPDATA%\Kelevra`.

## Что уже работает

- код доступа: конфиг забирается с сервера подписки и проверяется до сохранения;
- кнопка «Подключить»: приложение поднимает ядро, ждёт его и показывает состояние;
- трафик и срок подписки в окне;
- профиль перекачивается раз в час, как в мобильном клиенте;
- ядро скачивается и распаковывается самим приложением;
- профиль с сервера чинится под компьютер: из него убираются поля, которые
  работают только на телефоне (иначе ядро не стартует вообще);
- два режима: **весь трафик** (туннель, нужны права администратора) и
  **только прокси** (без прав; ядро прописывает себя системным прокси).
  Режим и причина видны в окне, кнопка «Включить полную защиту» перезапускает
  приложение через окно UAC.

- **отказ виден**: если приложение не смогло запуститься, оно говорит об этом
  окном с причиной, а не пропадает молча; всё, что оно делает, пишется в журнал
  `%LOCALAPPDATA%\Kelevra\kelevra.log`;
- второй запуск не поднимает второе ядро, а открывает окно уже работающей копии.

## Если не запускается

Запустили `Kelevra.exe`, а окна нет — приложение скажет причину само, окном
с текстом; текст из него копируется целиком по Ctrl+C. Если и окна с причиной
не появилось, причина всё равно записана — в файл:

```
%LOCALAPPDATA%\Kelevra\kelevra.log
```

(вставьте этот путь в адресную строку проводника). Файл нужен целиком: в нём
видно и запуск приложения, и всё, что случилось после.

Отдельный случай — **нет компонента WebView2**: окно приложения рисует он, и в
некоторых сборках Windows 10 его нет. Приложение об этом скажет и даст ссылку
на бесплатный установщик Microsoft.

## Чего ещё нет

- **подписи исполняемого файла.** Windows показывает предупреждение SmartScreen
  при первом запуске и после каждого самообновления. Лечится только покупкой
  сертификата подписи кода — это не работа кодом.
- **TUN без прав администратора.** Полная защита требует прав; без них
  приложение честно говорит об этом и работает прокси-режимом.

Трей и автозапуск с Windows тут раньше стояли как «нет» — они есть
(`cmd/kelevra/trey_windows.go`, `internal/avtozapusk`, сцены стенда 8-10).

## Сборка

```
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -ldflags "-H=windowsgui -s -w" -o Kelevra.exe ./cmd/kelevra
```

Windows для сборки не нужен: в приложении нет ни одной строки на C.
На Linux тот же код собирается и запускается без окна — интерфейс тогда
открывается в браузере по адресу, который приложение печатает при старте.
Так проверяется вся работа приложения там, где Windows нет.

Устройство и причины решений — в [ARHITEKTURA.md](ARHITEKTURA.md).
